# Neon Nexus E-Sports Club

Eight mobile-responsive HTML pages for the UCCD2323 E-Sports Club case.

## Run locally

Open `index.html` in a browser, or serve this folder with a local web server. Internet access is required for the Bootstrap, jQuery, Google Fonts, Unsplash images, YouTube embed, and the REST API demonstration.

## Assessment feature map

| Requirement | Implementation |
| --- | --- |
| Cookies | `index.html` saves a visitor name and gives returning visitors a personalised greeting. |
| Session Storage | `about.html` displays the number of pages viewed in the current session. |
| Local Storage | `tournaments.html` stores a registration preference; `contact.html` automatically saves/restores a message draft. |
| jQuery REST API | `rankings.html` uses `$.getJSON()` with JSONPlaceholder and renders mock live scores. |
| Social media plugin/widget | `community.html` provides a feed-widget simulation and Web Share / clipboard fallback. |
| jQuery effects | `players.html` filters player cards with fade effects; `gallery.html` has a jQuery lightbox. |

Replace the sample club names, dates, people, photos, Discord URL, and event details with your group's final content before submitting.
